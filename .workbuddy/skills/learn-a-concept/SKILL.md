# learn-a-concept

> 个人概念学习资料生成器。输入一个概念，输出一份 9 章节结构化的 markdown 学习笔记。

## 作业建议维度覆盖（设计对照表）

作业图里建议 Skill 能根据概念自动组织学习材料，包含 7 个维度。本 Skill 模板**全部覆盖**，对应关系如下：

| 作业建议维度 | 对应本 Skill 章节 |
|---|---|
| 学习目标 | §0 学习目标（读完应该能做什么） |
| 核心问题 | §3 核心要点（5-8 条），每条以问题或回答形式呈现 |
| 结构化解释 | §1 一句话定义 + §3 核心要点 + §6 例子/类比 |
| 应用案例 | §6 一个例子 / 类比（用一个工作或生活场景） |
| 概念辨析 | §4 常见误解（用 ❌ → ✅ 对比条） |
| 自测问题 | §7 我真的懂了吗？（自检 3 题） |
| 参考来源 | §8 下一步能去哪儿（带真实链接） |

另外本 Skill 多了 §2 解决什么问题（明确痛点驱动）和 §5 跟其他概念的关系（横向网络），共 9 章节。

## 触发方式

- 直接调用 Skill：`learn-a-concept: <概念>`
- 自然语言：「帮我学一下 X」「X 是什么」「讲讲 X」

## 工作流

1. **接收概念**：从用户输入中提取要学的概念（中文 / 英文 / 术语都行）
2. **定位输出目录**：本仓库的 `notes/` 目录（绝对路径：`D:/wawa/concept-skill-lab/notes/`）
3. **处理同名文件**：
   - 如果 `notes/<概念>.md` 已存在 → 读取现有内容，**追加 / 更新**而不是覆盖
   - 不存在 → 新建
4. **文件名规则**：
   - 中文概念：转拼音 kebab-case（如「大模型的上下文」→「da-mo-xing-de-shang-xia-wen」），或在 kebab-case 里直接用中文（保留语义，看哪个方便）
   - 英文 / 拉丁字母概念：直接 kebab-case（如 `Large Language Model` → `large-language-model`）
   - **要按序编号**：`01-`、`02-`、`03-` …（如果已经有 `01-` 和 `02-`，新的就是 `03-`），方便回看时按顺序展开
5. **生成内容**：严格按下面 9 章节模板
6. **落盘写入**：`notes/<编号>-<概念>.md`
7. **回执**：在控制台输出「已写入：`<绝对路径>`」

## 输出模板（9 章节，一个不能少）

````markdown

> 一句话总结：用一句话讲明白这是什么（不超过 30 字）。

## 0. 学习目标（读完这份资料你应该能...）

- [ ] 用一句话向别人讲清楚 <概念> 是什么（不超过 30 字）
- [ ] 说出 <概念> 解决的核心问题（场景 + 痛点）
- [ ] 列出 <概念> 的 3-5 个核心要点
- [ ] 指出至少 2 个常见误解并给出正确理解
- [ ] 区分 <概念> 跟至少 1 个相似概念
- [ ] 用一个具体例子演示 <概念> 是怎么用的
- [ ] 回答 §7 的 3 道自检题
- [ ] 知道 <概念> 深入学习该去哪儿（给 2-3 个真实来源）

## 1. 一句话定义

## 4. 常见误解

## 6. 一个例子 / 类比
````

## 注意事项（生成时必须遵守）

- **不编造**：如果某个章节信息不足，**诚实写「暂无可靠来源，待补」**，不要瞎编。正确性 > 完整性。
- **章节一个不能少**：9 个章节全部生成，缺资料的章节也要占位 + 标注。
- **参考资料给真实链接**：§8 给的资源必须是真实存在、可访问的；找不到具体 URL 就只给名称 + 出版社 / 作者 / 年份，不编 URL。
- **先读后改**：如果文件已存在，先 Read，再 Edit / Write，绝不直接覆盖原资料。
- **编号顺序**：每次生成前先 `ls notes/` 确认下一个编号是多少。
- **输出路径 hardcoded**：本 Skill 的输出目录是 `D:/wawa/concept-skill-lab/notes/`。如果仓库迁位置，要先来这里改。
